# MoonShineR fixture provenance

`moonshiner_1_2_0.csv` is generated by a real R execution of
`MoonShineR::predict_lux()` with `darksky_value=0`, sea-level elevation, UTC,
and one-hour cadence. The four two-day cases span northern/southern/equatorial
and polar sites, four seasons, and differing lunar phases.

Pinned environment:

- `rocker/tidyverse:4.5.2`, digest
  `sha256:4813816ad695004b738ccfff8513ce43f017e6fe78fb273aafd0bee4d4e1070a`;
- MoonShineR 1.2.0, CRAN mirror commit `9307aadfa003315d455bbe491f55bcd6fa06e968`;
- suncalc 0.5.4, CRAN mirror commit `9c1cde30060c86c5e62a366609e1bd01c92894b8`;
- REdaS 0.9.4, CRAN mirror commit `be50ce2c5e210817192dcb5859ec4da34a097abb`.

Regenerate with `scripts/reproduce_moonshiner_fixture.sh`. LIPE is evaluated
using MoonShineR's phase angle, distance, and altitude columns, isolating the
illuminance model from differences between Skyfield and suncalc astronomy.
MoonShineR includes waxing/waning asymmetry, opposition surge, an empirical
0.863 calibration, and a different extinction curve; LIPE does not. Differences
are therefore expected theory differences, not parameters to fit away.

`test_end_to_end_moon_geometry_and_illuminance_against_moonshiner` is a
separate end-to-end benchmark. It deliberately uses LIPE's DE421/Skyfield
altitude, phase, and distance before comparing lux. MoonShineR obtains geometry
from suncalc, so this is an independent but approximate reference, not a JPL
accuracy authority.
